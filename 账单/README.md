# 账单收件箱

每月的原始导出和成品都放在这里，一个期间一个文件夹：

```
账单/
├─ 2026-11/
│  ├─ 微信支付账单流水文件(20261101-20261130)_xxxx.xlsx   ← 原始导出（只读）
│  ├─ alipay_record_xxxx.csv                              ← 原始导出（只读）
│  ├─ 11月账单.xlsx                                       ← 命令生成的成品（真透视表）
│  └─ 11月账单_处理报告.md                                 ← 命令生成的核对报告
└─ README.md
```

用法：

```bash
python scripts/run_month.py --dir 账单/2026-11
```

- 自动识别目录里的微信 xlsx（文件名含「微信」）和支付宝 csv（含 `alipay` 或「支付宝」）；
- 成品名按目录名推断：`2026-11` → `11月账单.xlsx`；多个月份可以放一个目录（如 `2026-09-10` → `9、10月账单.xlsx`）；
- 原始导出**不会被修改**，成品是覆盖式的。

> 这个目录里的账单文件已在 `.gitignore` 中，不会被提交到仓库。
