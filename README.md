# monthly-bills

把**微信支付 xlsx** 和**支付宝 csv** 账单，一条命令变成一张 9 列、带**可刷新数据透视表**的 Excel，
并输出核对报告。支持自动分类、待确认兜底、历史映射学习。

> 一个 DSH Agent Skill + 可独立运行的 Python 引擎。数据全程在本地处理，不上传。

## 特性

- **解析**：微信 xlsx（自动定位第 18 行表头）+ 支付宝 GBK csv（`\t,` 分隔、页脚过滤、HTML 实体还原）
- **清洗**：删 0 元行、退款按净额入账、交易关闭处理、代收代付排除
- **分类**：固定字典（22 支出类 + 4 收入类）+ 商户映射 + 关键词规则 + 兜底
- **对账**：用两家账单自带的"共 N 笔 / 收入 / 支出 / 中性"数字做校验，不平就停
- **真透视表**：openpyxl 不能创建透视表，所以用「模板 + Excel COM 刷新」保留可展开/刷新的原生透视表
- **幂等**：保留交易单号去重，同一个月重复跑结果一致

## 快速开始

依赖：Python 3.10+、`openpyxl`、`PyYAML`；要自动刷新透视表需本机安装 Excel（Windows）。

```bash
pip install openpyxl pyyaml

# 1) 把两个导出文件放进 账单/2026-11/
#    微信：我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单 → 用于个人对账（xlsx）
#    支付宝：我的 → 账单 → … → 开具交易流水证明 → 用于个人对账（csv）
# 2) 一条命令
python scripts/run_month.py --dir 账单/2026-11
```

产物：

- `账单/2026-11/11月账单.xlsx` — `Sheet1`（真透视表）/ `合并账单`（9 列数据）/ `待确认` / `处理说明`
- `账单/2026-11/11月账单_处理报告.md` — 行数统计、官方口径核对、分类结果、待确认清单

## 输出长什么样

`合并账单` 固定 9 列：`交易时间 | 交易类型 | 交易对方 | 商品 | 收/支 | 类型 | 金额 | 交易状态 | 来源`，
按时间倒序、带自动筛选、金额 `¥` 格式、微软雅黑排版。

`Sheet1` 是一张**原生数据透视表**：行 = `收/支` + `类型`，值 = 求和 `金额`。
数据换了以后，在 Excel 里按 `Alt+F5` 或右键刷新即可；`run_month.py` 会自动刷新一次。

## 分类字典

分类是**固定字典**，不允许自由发挥（这是跨月可比的前提）：支出 22 类、收入 4 类。
判定标准、典型商户、旧标签别名都写在 [`scripts/分类字典.yaml`](scripts/分类字典.yaml)。
想加类型：改字典 → 同步 `rules.yaml` → 重跑。
